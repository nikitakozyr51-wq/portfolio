Портфолио — готовый сайт и исходники

Для просмотра после распаковки нужен Node.js 22+.
Откройте терминал в этой папке и выполните npm start.
Затем откройте http://localhost:4174 в браузере на этом же компьютере.
npm install для просмотра не нужен: папка dist уже собрана.
Открытие HTML двойным щелчком не заменяет запуск сервера.

Для повторной сборки: npm ci, затем npm run build.
Проверки: npm test. Настройка Vercel: vercel.json.
Все ограничения и результаты проверки: docs/ACCEPTANCE.ru.md.
Pencil-макет скачивается отдельно из ветки download-pencil.
