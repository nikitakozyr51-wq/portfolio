## Обновление

Локальная папка привязана через игнорируемый `.vercel/project.json`.
Вход CLI хранится в пользовательском профиле вне репозитория.
Репозиторий `nikitakozyr51-wq/portfolio` подключён к Vercel.
Production-ветка — **`desktop`**: её новые коммиты автоматически публикуются
на постоянном адресе. Изменения нужно сначала собрать, проверить и отправить
в эту ветку. Макеты Pencil, кэши и учётные данные в коммит сайта не включаются.

Ручная публикация через CLI остаётся доступной из корня проекта:

```sh
npm run build
npm test
npm exec --yes --package vercel@64.5.0 -- vercel deploy --prod
```

Vercel выполняет собственную сборку с production-доменом для canonical и sitemap.
На сервер отправляются исходники для сборки; кэши, макеты Pencil, локальные
артефакты и учётные данные исключены через `.vercelignore`.
