# Работа с проектом на компьютере

В этой папке собраны все 28 страниц портфолио, исходный снимок Framer,
готовый сайт, редактируемый макет Pencil, изображения, шрифты и результаты
проверок. Отдельные облачные настройки для просмотра сайта не нужны.

## Открыть проект в Codex

1. Скачайте ZIP ветки `desktop` репозитория `nikitakozyr51-wq/portfolio`.
2. Распакуйте архив в отдельную папку, например `Projects/portfolio`.
3. В приложении Codex откройте эту папку как локальный проект.
   Папка должна содержать этот файл, `package.json`, `source/` и `design/`.
4. Создайте локальную задачу и напишите: «Прочитай AGENTS.md и LOCAL-START.ru.md,
   проверь запуск проекта и подключение моего установленного Pencil».

Сам переход с сайта в приложение не меняет место выполнения существующего
облачного чата. Локальный агент должен видеть путь к этой папке на компьютере.
Откройте именно распакованную папку, а не ZIP.

Если Git уже установлен, вместо ZIP можно выполнить в выбранной родительской
папке:

```sh
git clone --single-branch --branch desktop https://github.com/nikitakozyr51-wq/portfolio.git portfolio
```

## Посмотреть сайт

Нужен Node.js версии 22 или новее: https://nodejs.org/

- Windows: откройте `start-site.cmd`.
- macOS: откройте `start-site.command`.
- На любой системе можно открыть терминал в папке проекта и выполнить
  `node scripts/open-local.mjs`.

Скрипт запускает готовую сборку `dist/` и открывает её в браузере после запуска
сервера. Порт выбирается автоматически. Для просмотра не нужно устанавливать
npm-зависимости, входить в Vercel или настраивать облачную среду. Пока сервер
работает, оставьте окно терминала открытым; для остановки нажмите Ctrl+C.

Для разработки и повторной сборки:

```sh
npm ci
npm run build
npm test
node scripts/open-local.mjs
```

## Макет Pencil

Откройте `design/portfolio-draft.pen` в установленном редакторе Pencil.
Оставьте `design/assets/` и `design/fonts/` рядом с ним: макет использует
относительные пути. Инструкция и ограничения находятся в `design/README.ru.md`.
Изменения макета сами по себе не меняют код сайта.

## Что передано

- `source/` — исходный опубликованный снимок Framer и локальные медиа.
- `dist/` — готовый сайт; `src/`, `scripts/` — адаптации, сборка и запуск.
- `design/` — `.pen`, ресурсы, шрифты, схема и отчёт проверки.
- `docs/` — план миграции, результаты проверки и ограничения.
- `tests/` и `artifacts/` — проверки, измерения и снимки экрана.

Кэши, `node_modules`, облачные учётные данные и временные сессии не переданы.
Результаты старых экспериментов в `artifacts/before-*` исторические; актуальная
оценка находится в `docs/ACCEPTANCE.ru.md`.

отдельно. Пароли и ключи не входят в проект.
