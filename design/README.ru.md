# Редактируемый макет

`portfolio-draft.pen` — черновик в открытом формате pen.dev 2.21. Его слои
получены из измерений работающего сайта в браузере, а не нарисованы на глаз.

В файле представлены все 28 страниц на ширинах 1440 и 390 px. Текст,
изображения и контейнеры — отдельные слои. Повторяющиеся кнопки вынесены
в компоненты; фактические колонки CSS Grid записаны в скрытые группы
`GRID GUIDES`. Их можно включать при проверке сетки. Значения CSS дополнительно
сохранены в metadata слоёв.

Рядом с каждым макетом расположен снимок исходной страницы для сравнения.
Снимки являются эталонами и не заменяют редактируемые слои. Видео представлены
постерами или статичными фрагментами браузерного снимка; плееры работают на сайте.

Открывайте `.pen` вместе с папкой `assets/`. Перед проверкой установите
Inter Tight из `fonts/`. Старой версии Pencil может понадобиться обновление,
чтобы открыть формат 2.21. Сохраните копию файла перед конвертацией редактором.

**Статус: отрисовка в самом Pencil ещё не проверена.** Проверка JSON,
опубликованной TypeScript-схемы, уникальности слоёв, ссылок на компоненты и
изображения не доказывает пиксельного совпадения в редакторе. Перенос строк,
режимы наложения, повороты и маски требуют этой проверки. Абсолютные позиции
сохранены по размерам браузера; это не автоматически восстановленные
адаптивные constraints Framer.

pen.dev CLI 0.3.12 установлен в облачной среде, но операции открытия/рендера
требуют авторизации. `pen status` сейчас сообщает `Not authenticated`.
Для продолжения нужен вход в pen.dev или `PEN_CLI_KEY` в защищённых настройках
среды. Ключ не следует отправлять сообщением в чат.

Схема: https://docs.pen.dev/for-developers/the-pen-format

CLI: https://docs.pen.dev/for-developers/pen-cli

Макет создаётся `scripts/make-design.py` из `artifacts/design-dom/` и
`artifacts/screenshots/`, которые сохраняет браузерная проверка. Это собственный
конвертер по открытой схеме, а не подтверждённый нативный HTML-импорт pen.dev.
