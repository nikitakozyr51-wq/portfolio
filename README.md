# Nick Kozyrev — portfolio

Полная опубликованная версия `desiredesign.framer.website`, подготовленная для
отдельного размещения. Сохранены все 28 маршрутов: главная, три представления
работ, категории, 10 кейсов, About, News, шесть статей и Old Home.

Это самостоятельный снимок опубликованного сайта с исходной сгенерированной
вёрсткой и JavaScript. Он не содержит редактор Framer и не заменяет его проект.
Внешние видеоплееры Kinescope продолжают использовать Kinescope.

## Запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run build
npm test
npm start
```

Сервер разработки использует порт 4174; изменить его можно переменной `PORT`.
Сборка находится в `dist/`. Сборка не обращается к Framer: все входные данные
уже сохранены в `source/`. Исходные HTML и ресурсы проверяются по SHA-256.

## Vercel

Проект подготовлен к импорту в Vercel: конфигурация — `vercel.json`, команда
сборки — `npm run build`, выходная папка — `dist`, preset — Other.
Секреты для работы самого сайта не требуются.

Для правильных canonical и sitemap задайте `SITE_URL=https://ваш-домен`.
Без него сборка использует стандартный production URL Vercel, если он доступен.
Локальная сборка без домена не генерирует sitemap и удаляет старый canonical.
Все пути ресурсов при этом используют текущий домен, без адресов localhost.

Публикация ещё не выполнена: в облачной среде нет авторизации Vercel.
После публикации нужно проверить прямые URL, MP4, Kinescope и загрузку сайта
из России без VPN. Работоспособность Vercel в конкретной сети нельзя доказать
локальной проверкой в этой среде.

## Как устроен перенос

- `source/` — неизменённые HTML, код, медиа, бинарные коллекции и 61 точный
  вариант изображений. Файлы исходного проекта на Framer не менялись.
- `scripts/build.mjs` — воспроизводимые адаптации сохранённого кода. Обработка
  JavaScript использует синтаксический разбор; неподходящий снимок останавливает сборку.
- `src/compat.js` — локальное чтение коллекций, локализация ресурсов
  и исправление неверно заданных видео. Данные коллекций не переписываются побайтово.
- `site.config.json` — реальные имя и Telegram из оригинала, флаги исправлений.
- `design/portfolio-draft.pen` — отдельный редактируемый черновик макета.
- `docs/MIGRATION-PLAN.ru.md` — подробный план и результаты исследования.
- `docs/ACCEPTANCE.ru.md` — актуальные результаты проверки и оставшиеся ограничения.

В новой версии исправлены шаблонные имя/контакты мобильного меню, HTML вместо
адреса видео. Оформление и остальные
материалы сохранены. Встроенное редактирование и аналитика Framer отключены.

Изменения в `.pen` не обновляют сайт автоматически. После согласования макета
их нужно перенести в код и повторить затронутые сравнения. Сгенерированный код
сохранён ради точности; переписывание на удобные React-компоненты — отдельный
этап с теми же визуальными эталонами.

## Проверки

```sh
npm test
npm run design:validate
```

Первая команда проверяет чтение диапазонов коллекций и обработку адресов.
Вторая проверяет `.pen` по опубликованной схеме 2.21, ссылки на компоненты
и наличие локальных изображений. Она **не проверяет отрисовку в Pencil**.

Для браузерной проверки нужны Python, Playwright и Chromium. При работающем
сервере запустите `python scripts/audit-site.py`. Скрипт сохраняет результаты
в `artifacts/`, сравнивает 28 страниц на ширинах 1440 и 390 px и блокирует
обращения к доменам Framer. `PORTFOLIO_TEST_URL` задаёт проверяемое размещение.
`CHROMIUM_PATH` задаёт путь браузера. Для нового полного прогона удалите или
переместите старые `artifacts/production-comparison-*.json`: прерванный прогон
продолжается с уже проверенных сочетаний. После изменения сборки старые
результаты использовать нельзя.

Скрипт `scripts/check-flows.py` проверяет навигацию, меню и несколько видеосценариев
на локальном сервере. Снимки браузера не включены в сборку сайта.
